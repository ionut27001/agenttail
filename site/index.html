    what you get
    
      
    Everything the agent does, as it does it
    
    
    
    
    
      
    ✍️
    Live editor typing
    Follows the file the agent is editing and types each edit in place, with a short highlight sweep. The tree keeps the heat: edits, failures, deleted files.
    
      
    🎭
    Console on stage
    A running command brings the console up over the editor; an edit sends it back; a quiet console shrinks to a rail. Job progress, spinners, exit codes.
    
      
    💬
    Chat and Log
    Chat reads like a conversation, with thinking and tool calls folded. Log is the full trajectory, with a summary per turn, exportable as Markdown.
    
      
    👥
    Several agents
    Every agent active in the last 30 minutes, grouped by git repository, each in its own colour. Alt+W opens the watch wall.
    
      
    🐾
    Tail, the mascot
    Reacts to passing and failing commands, cheers when a turn ends, thinks out loud and plays one of ten games on a long think. You can take over.
    
      
    🧮
    Cost, tokens, TOK/S
    Tokens, output speed and cost per session and per turn. For Claude Code, what the tokens would cost at API list prices, even on a subscription.
    
      
    ⏪
    Replay
    Finished sessions replay through the same pipeline, typing included, at the speed you pick.
    
      
    🔒
    Stream mode
    Secrets and identity are redacted on the server, before anything reaches the browser. If redaction fails, the event is dropped, never sent raw.
    
      
    🎛️
    Control, opt-in
    With --allow-control, start and drive your own DeepSeek Harness sessions: messages, approvals, stop, model switch. Token-protected.
    
    
    
  
    

  
  
    
    
    
      
    
      
    
        
        
        
        
        
        
        
        
      
    
    
    
    
    
      
    
        
    meet tail
    
        
    The logo, come to life
    
      
    
      
      
        
    • It watches. The eye follows your pointer; left alone it glances at whatever the agent is busy with.
      • 
        
    • It reacts. A hop when a command passes, a shake and a sweat drop when one fails, confetti when a turn ends.
      • 
        
    • It thinks out loud. Dots rise into a bubble with a clock, the latest thought and some nonsense. Five silent minutes and it dozes off under a STALLED? warning.
      • 
        
    • It plays. On a long think it plays one of ten games by itself. ▶ play hands you the controls: arrows and space, Esc to give them back, N for the next game.
      • 
        
    • It likes pets. Not too fast.
      • 
      
    
    
    
  
    

  
  
    
    
    
      
    ten games
    
      
    What Tail plays while the model thinks
    
      
    Each one is playing itself right now. Click one to take over; Esc hands it back.
    
    
    
    
    
  
    

  
  
    
    
    
      
    
        
    the whole team
    
        
    One pane per agent
    
      
    
      
      
        
    • A small agenttail each. Editor, console, scoreboard, TOK/S, context meter, and a Tail in the agent's colour.
      • 
        
    • The stage follows the agent. Commands bring the console up; replies run as captions.
      • 
        
    • Waiting is visible. waiting on the model with a clock, then stalled?. Quiet agents shrink.
      • 
        
    • One tree for the team. Every file the agents touched, with a flash when two of them edit the same one.

    stream mode
    
      
    
    
    
    
    
      
    
        
    safe to stream
    
        
    Your secrets stay yours
    
      
    
      
      
        
    • Read-only by default. It never writes to your agent's session store, workspace or transcripts.
      • 
        
    • Localhost only. Binds to 127.0.0.1, with Host and Origin checks against DNS rebinding and CSRF.
      • 
        
    • Stream mode is on by default. Keys, tokens, emails, user names, IPs and opaque ids are redacted on the server. It fails closed.
      • 
        
    • No telemetry, no CDN. Fonts and editors are vendored; it works offline.
      • 
      
    
    
    
  
    

  
  
    
    
    
      
    sources
    
      
    Reads the logs your agent already writes
    
    
    
    
    
      
    DeepSeek Harness
    ~/.dsh/sessions/**/session.v4.jsonl.zstd
    Edits, commands, background jobs, thinking, tokens and cost by peak band. Opt-in control.
    
      
    Claude Code
    ~/.claude/projects/**/*.jsonl
    Messages, thinking, tool calls, subagents, custom titles, turns, and what the tokens would cost on the API.
    
      
    Antigravity CLI
    ~/.gemini/antigravity/**
    Normalized messages, thinking, tool calls and file edits.
