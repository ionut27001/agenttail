## End-to-end demo (2026-10-20, real dsh)

Scratch `DSH_HOME`, scratch workspace in the allowlist, an Ollama provider
patch, `--allow-control --no-stream-mode`, driven through the control API.
The ACP catalog listed `deepseek-official` and `ollama` models; the default,
`deepseek-official/deepseek-v4-flash`, was used.

1. `session/begin` → owned session, preset `workspace-write` (2.3 s).
2. First message → approval for `echo approval-ok` → Approve → dsh log:
   `approval/decided allowed-once`, tool result `approval-ok`,
   `turn/end completed`.
3. Second message → approval for `Start-Sleep -Seconds 60` → Approve → after
   6 s, Stop → `tool call aborted`, `turn/end aborted (user)`; stop reason
   `cancelled`.
4. Close → no dsh ACP process left running.
5. Audit log: start, message ×2 (lengths only), approve ×2, stop, close.

## Agent pane (from review feedback)

- Chat and Log render markdown as DOM nodes (never `innerHTML`): headings,
  nested and ordered lists, task boxes, tables with alignment, quotes, rules,
  fenced code with its language, and inline bold, italic, strike, code and
  http(s) links. Thinking blocks in the Log render it too; their one-line
  preview and the console text drop the markers.
- The ⇥ button in the agent header (or `Ctrl+Shift+.`) docks the agent pane
  as a full-height column on the right, beside the editor and console, with
  its own resize handle. The choice is remembered.
- UI tests cover both (550 checks in the final `npm test`).

worktree per task; every change reviewed, tested and merged here).
